# Reversed failed-break exit grid

Frozen before scoring. Test 4 stops (6, 12, 18, 24 index points) crossed with 5 targets (6, 12, 18, 24, 36 points) on the same 187 unfiltered reversed entries from October 4, 2023 through October 3, 2024. Includes the prior 12/18 control. One MNQ, identical entry, 30-minute cap and conservative fill rules. Base round-trip costs $3.50; stress $5.50. Report all results. Rank by stressed net P&L; break ties by smaller stop, then smaller target.

Only if the leader has positive stressed P&L, compute simultaneous one-sided lower bounds for its stressed expectancy and session-return advantage over cash using the existing circular three-session bootstrap (seed 247, 19,999 draws, 24-policy allowance, two endpoints). Require both bounds above zero to score that single frozen pair on the subsequent 200 sessions. That period has been seen in related strategy research. A positive retrospective result is exploratory and requires independent data.
