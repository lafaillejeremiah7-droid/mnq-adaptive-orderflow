# Offline account survival replay

Run `python3 -m scripts.survival_stress examples/ILLUSTRATIVE_survival.json` from the checkout. Every number in that fixture is invented. The JSON output carries the declared source, rule reference, scenario assumptions, input SHA-256 and seed. The program has no connection to a brokerage or to the sizing gate. Match the rule document and data independently before interpreting a replay.

## What the model accepts

The example is a complete schema. Supply one flat-at-open, flat-at-close policy, one outright MNQ or NQ quarterly contract, a constant whole-contract size, and every eligible session in chronological order, including zero-trade sessions. Second offsets run from the beginning of the trading session. Candidates must be ordered and disjoint. Each candidate includes the ex-ante stop distance and the signed, gross **per-contract P&L in ticks** at ordered intratrade marks followed by the gross exit fill. Positive ticks represent gains for either direction. Historical inputs require documented entry and exit fills or a separately validated fill model, complete ordered marks at the firm's breach-monitoring frequency, a session calendar and explicit cost assumptions. Candle extrema alone cannot supply the mark order. A contract roll requires a separate run. Source and rule references are supplied by the caller. The tool cannot independently authenticate them or identify omissions in a submitted calendar.

The only rule model starts with a supplied prior highest end-of-day equity and its matching official floor. The floor equals that high minus a fixed trailing distance, optionally capped at a lock value, and ratchets only after a surviving close. Touching the active floor on a mark ends the account permanently. Touching session-opening equity minus the daily loss limit ends that session, and the next session resets the daily limit. Fees debit at entry and exit. The fail threshold takes precedence when both limits are touched. Firms using intraday ratcheting, a terminal daily-loss breach, soft daily pauses, withdrawals, overnight positions or different fee timing require a different model.

Proposals use the fixed dollar per-trade ceiling, reserve, remaining firm daily headroom, personal daily loss budget (realized losses consume it, profits cannot replenish it), firm and personal aggregate contract cap and at most two entries per session. A planned loss includes stop ticks, planned slippage ticks and both fees at the selected quantity. A proposal that could touch the failure or daily threshold is skipped. Actual losses can exceed the entry estimate. There is no attempt to trade through a rejected proposal or to raise size after a loss. The simulation assumes the stated size remains margin-eligible throughout every path and the input policy has already applied setup eligibility. Check these assumptions against the actual account. No output authorizes exposure.

## Stress scenarios and interpretation

Each scenario charges additional exit ticks on every exit. A stop-tagged scheduled exit also incurs its stop-failure debit. A forced exit replaces the scheduled exit with the first observed breach mark and incurs its own liquidation debit. Stress parameters represent adverse fills chosen by the researcher. The forced fill price, including its debit, is an explicit modeling assumption. Paths terminate on the first account failure, even if later recorded marks recover.

The chronological result replays every supplied session once. The moving-block bootstrap draws independent starting positions uniformly from all complete contiguous blocks, preserving order within each block and truncating the last at the source horizon. Scenarios use the same seeded draws. Reported frequencies cover account failure, any daily-limit touch, drawdown from the highest marked equity since path inception, and either terminal failure or a run of surviving EOD closes below the replay's prior closing peak. The final category treats failure as unrecoverable. A stopped session can still contribute its final equity to the closing peak. Each probability carries a two-sided 95% Wilson interval for **Monte Carlo error conditional on the supplied paths and model**. The appetite comparison uses the upper endpoint. The observed sample, chosen block length, underrepresented edge sessions of non-wrapping blocks, missing regimes and unobserved tails create additional uncertainty. Repeat with different prespecified block lengths and fee or shock assumptions. Block resampling alone cannot estimate the likelihood of a shock absent from the records.
